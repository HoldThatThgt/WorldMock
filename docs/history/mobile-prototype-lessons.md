# 手机交互穿刺经验归档

归档日期：2026-09-15。手机实验已经停止，本记录只保留方法、失败机制与证据结论，不维护其代码或运行入口。
用户在关联任务明确指出手机交互效率过低，改用 AgentSociety 2 与生活环境直接交互。

## 保留的经验

```mermaid
flowchart LR
    A[当时实际可见证据] --> B[人物解释与选择]
    B --> C[动作请求]
    C --> D[执行反馈]
    D --> E[确认结果与资源变化]
    E --> F[记忆形成]
```

这些环节必须分别记录。模型说已经观看、工具正常返回、页面出现控件，都不能代替结果证据。
这一经验直接进入新方案的观察、请求、接受、进度、结果及记忆事件协议。

| 穿刺观察 | 对新系统的约束 |
| --- | --- |
| ADB 能注入 GPS，但远端商家库存、天气、服务器时间不会随模拟时钟快进 | 世界的可控场景与外部数据依据分开，保存数据有效时刻；模拟值不能冒充当前外部事实 |
| 原生手机 Agent 会在 step 返回前执行动作，事后检查来不及阻止操作 | 身份、权限和参数校验发生在真实执行边界；动作回执不能写成完成结果 |
| 多模态上下文中的历史画面曾被解释为当前页面 | 保存实际观察正文、观察时刻和版本；历史内容与当前可见状态明确分开 |
| 非活跃媒体会话保留旧标题与进度，曾污染当前观看判断 | 标题、素材哈希和陈旧遥测只做检索线索，不能证明新接触或完整观看 |
| 约四十七分钟重复观看同一短片，摘要不断把重播解释为剧情继续 | 保存原始内容区间与每次接触事件；重复体验不删除，记忆摘要不能替代足迹 |
| 仅同标题和相邻录制区间，曾让首次非空对白被判为重复 | 记忆来源必须引用实际已交付内容；缺少语义证据保留无法确定 |
| 把“按偏好一直找视频”委托给手机模型造成长时间不交还 | 人物只提交有边界的生活动作，实际活动反馈时再决策；不让执行器替人物无限选择 |
| 采集正常不代表行为正常；修复后的测试通过也没有证明四小时完整观看 | 分开报告结构测试、真实模型、环境执行、语义质量与数据交付 |
| 页面给出的预计配送时间只有预估含义，尚未形成真实订单和送达 | 预计时间与实际环境送达事件分别存储；准备、排队与运输依据标明来源 |
| 恢复必须保存原人物状态、未完成活动及已发生轨迹 | 新方案使用人物与世界共同检查点，恢复到新分支，不覆盖父运行 |

## 已有证据的实际边界

关联任务：[调研手机模拟器交互能力](thread://01a07f1d-1a02-7a93-8860-e7a028dd7329?hostId=local)。
本次已调用任务读取接口，并核对其本地会话记录与现有工程文档。

旧工程在本次清理前执行全测：598 passed，19 subtests passed，11.76 秒。
该结果只表示旧工程程序边界的测试基线，不能迁移为 AS2 覆盖率，也不证明模型行为符合人类。
旧运行状态在本次检查中为 `stopped_by_user`；其旧四小时自动化为 `PAUSED`。
历史提交名与冻结目录不能作为当前工作目录的 Git 身份；本次检查根目录没有 `.git`。
