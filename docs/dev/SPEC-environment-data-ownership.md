## 用户目标

WorldMock-Dataset 管理具体世界的来源、地图、商品、内容、场景、离线采集构建和数据产物。
WorldMock 管理模拟器、数据结构、通用行为规则、加载校验、记录和导出。具体世界可由数据仓独立发布，
安装引擎后通过显式场景路径使用，不要求引擎源码目录中存在任何正式环境数据。

```mermaid
flowchart LR
    S[数据仓中的来源与构建工具] --> D[冻结环境目录]
    D --> E[WorldMock 加载与校验]
    R[引擎包中的通用规则] --> E
    E --> A[人物行动与世界结算]
    A --> O[运行记录与导出]
```

## 职责与接口

| 条款名称 | 冻结要求 | 验收依据 |
| --- | --- | --- |
| 正式环境归属 | WorldMock 根目录不再保留正式 corpora、catalog、scenarios；数据仓接收原张江环境及其来源、许可、冻结身份和构建工具 | 逐文件移交清单、字节核对、双方仓库目录核查 |
| 通用规则归属 | 固定类别、身体与交换常数、公式归 `worldmock.exchange`，由 `RULES_VERSION = 2` 绑定；可供性与人物映射只读包内资源，环境没有副本 | 独立导入、常数唯一归属与包资源身份测试 |
| 标题来自环境 | 内容标题、摘要、真实或合成来源直接写入 `catalog/contents.json`；场景结构 8 只引用环境，不另存内容标题 | 真实目录加载、严格旧字段拒绝与内容 app 绑定测试 |
| 活动效果归系统 | 动作效果按五个固定类别由 WorldMock 给出；环境只选类别与使用方式，不登记效果、代谢当量或动作时长 | 固定常数与目录拒绝旧字段测试 |
| 无隐式环境依赖 | 引擎导入不读取正式世界；不搜索 sibling 仓、不使用环境变量切换素材、不缓存另一世界的效果；缺输入明确失败 | 正式环境目录不存在时导入及完整生命周期测试 |
| 内容时长准入 | 内容时长为正整数且不少于 60 秒；动作不带时长 | 真实登记与最短时长反例测试 |
| 数据准备归属 | Dataset 准备清单与六个目录文件、结构 8 场景及内容摘要来源；WorldMock 提供规范图生成器与统一登记检查 | 目录发布、重生成比较与双方职责门禁 |
| 测试输入归属 | 引擎人工环境为七地点、八 app、六商品、七动作、十五内容与种子 7 图；完整回归通过 `--environment-root` 显式选重制后的发布环境 | 人工真实加载与完整回归输入字节回执 |
| 历史证据不可改写 | 已存运行、导出及其 frozen-inputs 是不可变证据；不重写历史字节，不提供旧格式运行兼容 | 历史输入摘要保持不变 |
| 双仓端到端 | Dataset 重制后的发布环境经过引擎真实加载、动作、关闭恢复和导出；端到端结果以当前版本真实运行回执判定 | 真实引擎动作链与当前提交的独立回执 |
| 实施验收 | 不新增第三方依赖，不增加兼容层、migration、fallback 或多余配置；遵守中文注释和英文错误输出；新行为通过 Uncle Bob Review | 依赖差异、风格门禁、变异验收报告 |

## 发布与约束

Dataset 发布 app、地点、商品、动作、内容与图，目录格式为 2；环境只有 catalog 与 scenarios，规则只从包读取。
分类、身体与交换常数不从环境读取；清单加六个目录文件的文件表绑定环境身份，场景用环境标识与版本钉定。
生产函数不得依赖测试环境。绝对路径只允许用于本次机器上的工具调用，不得写入源码、配置或交付清单。
收费模型模拟不属于此次整理验收；已有模型运行仅作为历史证据。

重写的人工小环境验证引擎独立安装后的生命周期，完整闭环以当前版本真实运行回执验证。购物、通勤、工作和多人互动的完整回归需要完整世界，
测试入口以 `--environment-root` 显式接收该输入，绑定目录与场景的真实字节；未提供时只选择仓内人工输入，
不查找数据仓或获取在线素材。引擎运行接口不增加配置层。
