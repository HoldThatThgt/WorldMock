# 地图、地点与门店供给问题分析记录

> 状态：历史问题分析入口；现行行为合同由 [地图与门店供给开发规格](SPEC-map-and-storefront.md) 承载。
> 更新日期：2026-09-20。

## 原始问题与当前裁决

原始问题是同一商品被绑定到单一门店，人物缺少可比较的门店供给，地点定义重复维护，营业和访问条件不完整。
当前裁决采用商品与供给分离、唯一冻结地点目录、显式活动环境、事件驱动营业与报价、道路事实查询，
以及真实呈现结果和共同检查点。人物自己选择，环境只判断与结算。

## 已修正的基线判断

| 原判断 | 当前证据与边界 |
| --- | --- |
| 八处外部地点没有冻结路线 | 基线已有十一处地点与二百二十份按方式命名的响应；正式引用、方式来源和运行可用性仍须分别验收 |
| 全部步行路线已验证 | 一百零四份步行响应与同端点驾车响应相同，不能以文件名证明步行方式；修复后以实际准入证据为准 |
| 外部平台没有地点选择能力 | 多个成熟平台及 AS2 都有选择机制；本项目因人物自主边界不采用其代选 |
| 地点经营业态可以直接代替活动环境 | 两者不同，活动环境须显式非空声明并进入候选、启动和恢复门 |
| 商品对象的价格就是门店成交价 | 共享商品规格不承担供给身份；成交价、卖方、库存和履约按供给 |
| 地图产出公开时只需署名 | 须按来源、数据库关系及实际公开方式判断；产出作品和其派生数据库义务不同 |
