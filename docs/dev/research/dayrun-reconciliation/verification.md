且实际四次请求后可能声称仅尝试一次。本次按库的明确异常类型判断；

运行阶段多 deployment 的构造验证不证明真实云端请求均匀分布。
画像抽取的首 key 限制没有现成 dayrun 修复可移植；本次明确登记缺口，不临时增加另一路轮转器。
这不妨碍核查和适用补丁整合完成，也不代表全链路分摊目标已完成。
