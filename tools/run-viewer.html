拖入导出目录

把 worldmock export 写出的导出目录拖到此处，或点击选择其中的 events.jsonl 与 manifest.json。
没有导出的运行（包括运行中和中途停下的）先导出：worldmock export --run-dir <运行目录> --output <新目录>，加 --cutoff 只导出到某个事件。
查看器在页面里从 events.jsonl 建索引（下方显示读取进度），展开一行时按字节区间读这一行的全文。
对象名称取自导出目录 assets 里冻结的环境目录，没有 assets 时显示为「名称缺失」；人物的 MEMORY.md 总结要同时拖入运行目录（或整个执行目录）。
所有数据只在本地浏览器内解析，不会上传。
